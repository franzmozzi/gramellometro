# AGI – Anti-Gramellinism Intelligence
 
L’ampia diffusione dei modelli linguistici di grandi dimensioni (LLM) nella produzione testuale richiede una nuova consapevolezza. La possibile presenza di testi di Massimo Gramellini e dei suoi emuli nei dataset di addestramento rischia infatti di compromettere lo stile dell'output generato. *Garbage in, garbage out*, in gergo informatico.  
 
Per monitorare e identificare le occorrenze indesiderate di stilemi gramellici, è però possibile automatizzare l’uso del Gramellometro. Le istruzioni fornite permettono di configurare un agente (utilizzabile in ambienti come Claude Projects, ChatGPT Custom GPTs o Gemini Gems) specializzato nel rilevamento di schemi indesiderati.
