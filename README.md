# AGI – Anti-Gramellinism Intelligence
 
L’ampia diffusione dei modelli linguistici di grandi dimensioni (LLM) nella produzione testuale richiede una nuova consapevolezza. La possibile presenza di testi di Massimo Gramellini e dei suoi emuli nei dataset di addestramento rischia infatti di compromettere l’output generato. *Garbage in, garbage out*, in gergo informatico.  
 
Per monitorare e identificare le occorrenze indesiderate di stilemi gramellici, è però possibile automatizzare l’uso del Gramellometro. Le istruzioni fornite permettono di configurare ambienti come Claude Projects, ChatGPT Custom GPTs o Gemini Gems, per istruirli a rilevare schemi indesiderati. In ambienti di sviluppo avanzati o a riga di comando, se ne caldeggia l’adozione sotto forma di agent autonomo.
